# How to use TACO

## How to verify code
- `unittest/`
  - Where the testing drivers are. This functions set the configuration for TACO (e.g. IntBitWidth, LoopUnroll) and check if it finds counterexamples.
  - Every driver has an associated test source code.
- `tests/`
  - Where the test source code is.
  - The code is composed of Java code and JML specification comments.
- `src/`
  - TACO source code. Includes its parser, compiler, AST reduction.
  - `src/ar.edu.taco/engine/precomiledmodules`
    - Some classes are already implemented in jdynalloy as precompiled files or are generated from Java code.

## How to navigate the TACO source code
The main function that the unittest drivers call is `check`. This receives the function call to test and whether it expects a counterexample or not.
This in turn ends up calling `TacoMain.run`. This is the function responsible for testing whether the test code compiles, simplifying it, parsing and translating the annotations, and eventually generating the Alloy file that is tested.
